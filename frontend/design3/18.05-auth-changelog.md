# Auth Changelog

## 2026-05-18 — Profile Navigation and Logout

### Summary

This update improves the frontend authentication flow after login.

### Changed files

- `index.html`
- `homepage.html`
- `profile.html`
- `login.html`

### What was implemented

- Added authentication-based navigation.
- Added Profile and Logout buttons for logged-in users.
- Added a Profile button on the homepage hero section next to `All Jobs`.
- Added Logout functionality on the profile page.
- Updated login behavior so the user returns to `homepage.html` after successful login.
- The Profile button is shown only when the user is logged in.
