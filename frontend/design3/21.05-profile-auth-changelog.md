# 21.05 – Profile Authentication Changelog

## Summary

Today I connected the profile pages with the real authenticated user data from the backend.

## Changed files

### Backend

- `AuthController.java`
    - Extended `/auth/me` so that it returns real user profile data.
    - Added `fullName`, `designType`, and `skills` to the response.
    - Improved registration so that the full name and role-specific designer fields are saved.

- `AuthRequest.java`
    - Added fields for `fullName`, `designType`, and `skills`.

- `UserModel.java`
    - Added fields for `fullName`, `designType`, and `skills`.

- `UserRepository.java`
    - Updated the `users` table structure.
    - Added database columns:
        - `full_name`
        - `design_type`
        - `skills`
    - Updated `save()` so new profile fields are stored.
    - Updated `mapResultSetToUser()` so new profile fields are loaded again.

- `pom.xml`
    - Added Spring Boot DevTools for easier local development.

## Frontend

### `register.html`

- Registration now sends:
    - full name
    - email
    - password
    - role
    - design type
    - skills

### `profile.html`

- Removed static profile data such as `Jane Doe`.
- The page now loads real data from `/auth/me`.
- The logged-in user’s name, email, role, creation date, and profile details are displayed.
- Added profile action buttons:
    - Send Message
    - Edit Profile
    - Logout

### `profile-edit.html`

- Removed static example data from the edit profile form.
- Kept the original layout and visual structure.
- The page now loads the logged-in user’s profile data.
- The preview updates dynamically when the user edits name, title, city, or country.
- Saving is prepared in the UI, but backend update logic is not connected yet.

## Important note

The local H2 database file `backend/data/projectdb.mv.db` was changed during testing, but it should not be committed.

The database had to be recreated locally because the old `users` table did not contain the new columns:

- `full_name`
- `design_type`
- `skills`
